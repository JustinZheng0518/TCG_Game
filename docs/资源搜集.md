## 本地文件

- `data/catalogs/pokemon-english-sets.json`：英文系列元数据。
- `data/catalogs/pokemon-english.jsonl.gz`：每行一条英文卡牌记录，`images.small` 与 `images.large` 为上游提供的地址。
- `data/catalogs/pokemon-multilingual-candidates.jsonl.gz`：多语言目录，包含中文名称和待核验图片地址。
- `data/catalogs/summary.json`：数量、覆盖限制、源提交与归档 SHA-256。
- `data/catalogs/source-checks.json`：网络访问证据和待完成项。
- `tools/collect_catalogs.py`：使用 Python 标准库重建目录；验证固定归档 SHA-256，不运行源仓库程序。
- `tools/download_images.py`：英文卡图下载器，支持按系列、大小图选择和断点续传；记录每个成功文件的来源和 SHA-256。遇到拒绝访问或限流即停止。

源数据压缩包缓存在 `/workspace/card-source-cache/`，不作为项目中的额外 Git 仓库。可通过脚本重新下载。当前所有生成目录合计约 3 MB；图片下载后的实际体积需单独测量。

## 可复现命令

在已有检出目录执行，不需要另建 Git worktree，也不需要 API 密钥：

```bash
cd /workspace/TCG_Game
python3 tools/collect_catalogs.py
```

下面的图片命令已在当前机器尝试，因网络策略返回 403 而未成功；不能描述为已经完成下载。网络允许后先验证一张，再验证一个系列，最后运行全量：

```bash
cd /workspace/TCG_Game
python3 tools/download_images.py --set base1 --limit 1
python3 tools/download_images.py --set base1 --all
python3 tools/download_images.py --all
```

高清图使用 `--size large`。成功文件和下载索引写入被 Git 忽略的 `data/images/pokemon/`；运行中的下载事实以 `download-index.jsonl` 与实际文件为准。目录中的 `image_status` 表示源数据收集时的状态。
