# 系列封面与概率公示

## 游戏内入口

宝可梦和篮球的“买包开包 / 采购开包”页面均直接显示封入位置、关键档位比重，旁边的“查看全部概率”打开完整面板。切换系列后跟随该系列实际卡池重新计算。

面板依次提供卡位抽法、各卡种概率、可搜索和筛选的全部单卡概率。卡牌详情也可直接进入该卡所在系列的概率面板，无需切换正在采购的系列。“评级中心 → 查看本卡评级概率”公开当前卡牌与机构的全部可达分数和标签概率。

### 低概率档位卡面

在卡位概率下面，宝可梦 12% 及以下的非空随机稀有档、篮球全部非普卡收藏档直接展示本档真实卡面、卡名、卡号与稀有度，点击可看单卡详情。每档先展示 4 款，其余通过“再看 8 款”逐批展开，全部卡面均可查看。宝可梦机会位、篮球收藏位与活动稀有加工档均按实际卡池展示；普通卡位、基础回落、普通新秀位、自选领取与缺素材回退不展示卡面墙；篮球普通平行 / 特卡 15% 档同样有图片，当前全部非普卡图片均已缓存到仓库。

### 计算口径

- 卡位比重：每一个独立抽取位置的互斥卡池权重，合计 100%。卡池内每条卡面记录等概率。
- 每份至少一张：已合并本份所有卡位中获得该卡 / 卡种的概率，不是把某档概率当成任意一张卡的概率。
- 十份至少一张：按十次相同规则、相同选择计算 `1 - (1 - p)^10`。这里“份”是包、盒或一次领取；活动的每日限制仍照常生效。
- 平均等待份数：`1 / p`，是统计期望，不是累计保底；0% 明示当前规则不会获得。
- 同一卡种可能在多个位置出现，先合并所有位置后计算。每份可以同时出现多个卡种，卡种表各行之和不要求为 100%。
- 计算针对每条真实卡面记录，不把同名、同编号但不同加工版本混在一起。

### 覆盖的获取渠道

| 渠道 | 公示内容 |
| --- | --- |
| 宝可梦常规包 | 3 基础位 + 1 保底位 + 1 机会位；逐系列区分 RR / RRR 回退、非空最高稀有档 0.1%、无追逐档及全高稀有卡池 |
| 宝可梦特色包 | 实际每包张数、均匀抽卡的单卡和整包概率 |
| 预组 | 58 基础 + 2 主力的游戏配方，合并两种位置计算整盒概率 |
| 活动 | 均匀卡池或产品实际配置；活动第五弹为 89% / 10% / 1% 工艺位，再除以对应工艺卡面数 |
| 任务、附属包 | 每次随机一张的真实单卡概率 |
| 礼盒与兑换 | 自选卡 100%、其他卡 0%，面板中更换选择会同步当前系列的领取选项，不伪装为随机抽卡 |
| 篮球一般包 | 4 基础位 + 1 收藏位，显示低编 0.1%、追逐特卡 0.1%、签字 1.9%、球衣 3%、其他限编 5%、平行 15%、特卡 15%、新秀 20%、基础回落 39.9%；未收录卡种为 0%，其位置回退基础池 |
| 篮球全命中卡池 | 无基础卡时五张均匀抽取，单独说明，不套用一般篮球收藏位比例 |

界面中的档位比例从实际抽取所用模型读取：宝可梦 `Game.packModel`、篮球 `Basketball.packModel`、预组 `Shop.deckPools`、活动 `Shop.eventPools`。`web/draw-odds.js` 合并独立位置的概率。篮球资源修正后增加追逐特卡位 0.1%，基础回落相应为 39.9%；/10 及以下签字、球衣也归低编位。缺素材档展示 0% 和空卡池，按实际抽法把原权重并入基础回落，不展示基础卡冒充稀有档。

### 评级

四项游戏预检（居中 / 四角 / 边缘 / 表面）独立抽取，原始分数分布为 7 分 2%、8 分 4%、8.5 分 10%、9 分 24%、9.5 分 38%、10 分 22%。1980 年前各减 1，1980—1999 年各减 0.5，未提供年份的卡与现代卡不减。各机构仍沿用游戏公式，按全部 `6^4 = 1296` 种组合精确汇总总分和标签。BGS Black Label 与 Pristine、CGC Pristine 与普通 10 分分别显示；未列出的结果为 0%。例如现代卡 BGS Black Label 为 `0.22^4 = 0.234256%`。

标准 / 加急只改变费用和等待时间，不改变评级分数。概率面板不读取已经生成的评级结果；送评仍只生成并保存一次，刷新不能重抽。这是游戏评级规则，不代表机构实际分数分布。卡展的预制评级展品按日期规则固定，不经过玩家送评抽取。

## 全系列封面

386 个可玩系列均有随站点提供的本地图片：

- 209 个宝可梦系列：原图源提供的真实商品封面，压缩为 WebP，标注“商品封面”。
- 27 个无商品封面的宝可梦活动 / 特典等系列：取该系列真实卡面，标注“卡面预览”。
- 150 个篮球系列：使用该系列已经校验的本地真实卡面，标注“卡面预览”。

图片与系列精确对应，不以其他系列封面替代，不用卡面伪装实体密封包装。数据在 `data/shop/set-covers.json`；宝可梦封面源自同一固定提交：

`https://raw.githubusercontent.com/duanxr/PTCG-CHS-Datasets/c3b6ac6ef803aad9d60e44d058359addf3a20883/img/<source_collection_id>/cover.png`

篮球图片沿用 TCDB 资料与本地预览。重建：

```bash
python tools/build_set_covers.py --cache /workspace/card-source-cache/chs-extra-images
```

系列选择器使用可滚动大图网格，电脑四列、手机两列，保留名称 / 代码搜索、时代 / 获得渠道筛选和收藏进度。小屏卡名换行，不压成细小字。

用户提出参考微信“集换社”。本次云环境无法直接进入微信小程序，相关网页与搜索请求返回 403，未声称实际查看其当前界面；实现以图片目录、分类筛选和清晰信息层级为目标，不复制其素材或假称复刻。

## 验证

`tests/draw-odds.test.cjs` 检查全部 386 个系列的模型、位置权重和预期张数，核对特定卡的精确概率、缺档回退、自选 100% / 0%、活动边界及全部封面与系列对应；并将评级枚举结果逐一对照实际送评路径的全部品相组合、三个年份区间和四家游戏机构。

`tests/browser_odds.py` 覆盖电脑 / 手机图片选系列、搜索筛选、各渠道概率、单卡查询、自选同步及评级概率；`tests/browser_collectibles.py` 回归开包、评级和卡展交易。图片已逐张通过 Pillow 解码检查。
