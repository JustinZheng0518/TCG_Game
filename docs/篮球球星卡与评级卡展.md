# 篮球球星卡、共用评级与卡展

本项目中“球星卡”仅指篮球，包括 NBA、WNBA 和篮球大学系列，不加入其他运动。简体中文界面；篮球保留真实原版卡面，部分球员有中文译名，其余保留原名，不把英文扫描图声称为官方简中版。

## 素材整理结果（2026-10-18）

来源为 [Trading Card Database 篮球目录](https://www.tcdb.com/ViewAll.cfm/sp/Basketball)，按年份和系列归档。

- 历史目录：76 个来源年份、3,834 个系列索引。目录不等于全部已接入可抽卡。
- 可玩卡表：150 个系列、30,962 条带正面缩略图依据的记录，跨度 1948—2026。部分重点系列额外整理 102 个平行 / 特卡子卡表。
- 随仓库提交：1,105 张经下载、Pillow 解码校验的 WebP 预览，每个系列均有图片；卡展篮球展品全部使用这些本地预览。
- 其余正面图地址从来源页面实际出现的正面缩略图路径转换；未逐张下载原图验证，展示时联网加载。原始读取累计遇到 9,934 条缺少正面依据的条目（含主表和同主表索引的重复读取），均未接入。外部图源不可用时，有本地预览的卡回退预览；不以其他卡面冒充缺图。

这是覆盖多时期的第一批资源，不是“全世界全部篮球卡已齐全”。不确定的签字材质、球衣使用情况、真实序号不编造。`/99` 是原版变体的印量标签，游戏可重复抽到该卡，不代表持有实体第几号，也不模拟全球仅 99 张。

目录、卡表、图片来源和校验结果分别在 `data/basketball/archive-sets.json`、`index.json`、`sets/`、`coverage.json`。重建命令：


Python 图片整理依赖见 `requirements-assets.txt`；网站运行不需要 Python 包。抓取使用低并发、请求间隔和仓库外缓存，不重复下载已有资源。

## 篮球包与行情

篮球柜台提供买包、撕包、单卡买入和出售、收藏、评级与卡展。宝可梦仍保留原店铺经营。共用钱包和存档，收藏默认汇总两类卡，可筛选运动与系列。

篮球为 **5 张数字体验包**，非实体 Hobby、Retail、Blaster、盒或箱的封入承诺。一般系列 4 张基础 / 新秀位，1 张特色位；特色位顺序概率：限编不超过 /10 的卡 0.1%，签字 / 签字球衣 1.9%，球衣 3%，其他限编 5%，平行 15%，特卡 15%，新秀 20%，余下基础。某档在该系列没有素材就回退普通卡，不凭空补出签字卡。部分高端系列普通清单本身全是签字或球衣，改从已有卡池均匀抽取并在界面说明，无法声称其稀有命中率仍为千分之一。

实际篮球产品的零售、Hobby、年份、地区、平行和“每盒平均”配置不同，不能以一套概率代表现实。数字包价格 ¥45 / ¥85 / ¥650、单卡估值、新闻波动均为游戏设计，没有接入全量真实篮球成交价。原版素材中的稀有类型来自实际清单 RC、AU、MEM / JSY、SN 等标注。

## 两类卡共用评级

PSA、BGS、CGC、SGC 四种游戏送评选项；标准 3 个营业日、加急 1 个营业日。费用从 ¥150 / ¥300 起，乘游戏机构系数并叠加卡价比例。营业日结算仍需支付店租；旧店铺有未结算顾客订单时，先回店完成结算。

提交时消耗一张可用散卡、扣费并保存结果，刷新不能重抽。取回前不可出售。每张评级卡独立编号、独立持有，卖出或交换不会误减同编号散卡。结果显示 GAME 证书。居中、四角、边缘、表面是**游戏预检**，并非四家机构都提供子分数；分数公式、旧卡磨损、机构差异和增值系数都是游戏简化，低分与送评费可能导致亏损。不对真实卡提供鉴定。

## 卡展

单人 NPC 模拟，门票 ¥20 / 营业日。三个展位各四件展品，每个展位有评级卡。可以直接买入、把自己的散卡 / 评级卡卖给摊主，也能选自己的卡换展品，按双方报价补钱或退差价。一次存档写入同时完成扣卡、收卡和资金变化；保存失败不改变持有状态。

同一展位位置当天只能成交一次，筛选类别不会绕过成交记录。每日最多向摊主售出 12 张，推进营业日后刷新。摊主对新秀、经典或评级卡有偏好收购价；市场估值不等于真实成交价。不是玩家联网交易。

## 调研后的理解

最大的区别是**价值锚点**：篮球通常收藏球员职业生涯里的位置与实物来源，宝可梦通常收藏角色、画面、版本，同时还有真实对战需求。两个市场都受品相、存量、受欢迎程度、评级数量和流动性影响，均存在长期收藏与短期投机。

| 维度 | 篮球 | 宝可梦 |
| --- | --- | --- |
| 收藏对象 | 球员、球队、赛季，特别是新秀身份 | 角色、画师、插画、系列、语言与加工版本 |
| 关键版本 | 基础 / 平行、限编、签字、球衣或球鞋等材质 | 稀有度、特殊插画、闪膜加工、活动 / 赛事版本 |
| 稀缺判断 | 需要核对确切变体、印量、签字方式及材质描述；球星同名卡差别可极大 | 需要核对语言、编号、印次、加工、活动来源；同角色同画面也可价格不同 |
| 需求变化 | 比赛表现、伤病、转队、荣誉、退役，及收藏人气 | IP 热度、画师 / 插画审美、补印与供应、对战强度 / 赛制变化 |
| 产品结构 | Hobby / Retail 等形态常有不同专属平行、盒均配置；不能把盒均写成每包必出 | 按具体地区和 set 判断包 / 盒封入；也不能把某地区保底推广到所有版本 |
| 评级 | 条件与真伪、签字或材质来源需分别考虑；高价不等于值得送评 | 同样看品相与真伪，也要区分语言、加工、印刷与版本；高分不保证回本 |

签字要区分亲签、贴签及认证；球衣的 game-worn、player-worn、未关联特定比赛等描述不能混为一谈。宝可梦同样有特殊限量和签字收藏品，不能简单说“篮球有限量、宝可梦没有”。授权随年代、品牌及授权对象变化，不能只用品牌名判断全部卡的 NBA、球队、球员或签字授权。
